Cybersecurity & AI Project

Network Anomaly Detection with Machine Learning for Niger

Built a machine learning system to detect abnormal network traffic using flow features such as packet count, byte count, protocol, ports, and connection duration.

Engineered traffic behavior features including packets per second, bytes per packet, and bytes per second, then trained an Isolation Forest model for anomaly detection.

Adapted the project to Niger’s digital infrastructure context, including universities, ISPs, government offices, banks, NGOs, and small businesses.
